# Journeys

One YAML file per journey: steps (say, drop a file, seed, run an agent, answer a card) and
checks on the world, run on a fresh tenant of its own with the real model. Reports go in
`docs/journeys/`. The shape is in `docs/design.md` §16; the first journey, "track what I eat"
then "log two eggs", comes in week 1.
