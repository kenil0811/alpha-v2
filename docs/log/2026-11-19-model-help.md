# 19 Nov 2026: help in Settings › Model

Kenil had to ask for his Claude token to be taken off Avilo's Alpha by hand, and asked for help
on how to set each way up. Settings › Model now has an ⓘ beside each way: on a Mac, Sign in in the
browser; on a server, `claude setup-token` on one's own computer and paste the token; for a key,
create one in the Claude Console. A token saved on a server has Delete, asked on the page
(`DELETE /api/model/token`, owner only, journaled, its sealed copy deleted). A key on a server now
reads "Key saved on this server", not the Mac's Keychain. ui-rules I3 updated.
