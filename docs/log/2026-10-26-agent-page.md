# 26 October 2026: an agent's page

Each agent already had its page at `#/agent/<id>` (its words, when it runs, on or paused, Run now,
its module, its runs each opening the run). Three changes: the way back from an agent's page goes to
Intelligence's agents, not Activity; its runs are under "Recent runs", not a second "Runs"; and a
click on a row's name in a table kept on its own pages (Intelligence's agents and permissions,
People, Tasks) opens that page, where before only the icon on hover did. Checked in Edge on the test
install's Circles, Closeness and LinkedIn export; the switch and Run now were not pressed. Its
standing permissions are not shown: `/api/permissions` does not say whose they are.
