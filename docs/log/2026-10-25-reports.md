# 25 October 2026: Settings › Reports

Vikas asked for one place to download reports. Settings › Reports (`Reports.tsx`) lists every module,
by its place in the tree, with its pages (PDF, through the page's own print route) and each table's
saved views (Excel or CSV; the whole table when it has none). A view's report is what the view
shows: its filters, search, sorts and columns, through the table engine, so it matches the screen.
A module filter and a period (all time, this or last month, this quarter, this year) narrow it; the
period reads the table's first date column, and a table without one says so. Nothing in the core
changed. Sending a report on a schedule waits for Kenil (item 15). Checked in the browser: Excel and
CSV downloaded, the period and module filters; the test install has no pages, so PDF went untried.
