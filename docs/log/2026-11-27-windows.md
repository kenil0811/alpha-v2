# Alpha on a Windows PC

26 and 27 Nov. The Windows design (a Claude Doc; Kenil said yes to its 20 calls, with call 13 on his
main Windows 11 account and call 2 as Windows 10 22H2 and 11 on Intel and AMD) built on the branch
`windows-installer`, its Windows runs on GitHub's Windows machine (`.github/workflows/windows.yml`).

Step 1, proven on GitHub's machine (branch `windows-wsl`): WSL2 runs there; the servers' setup and
release run inside an Ubuntu; Alpha answers on 127.0.0.1 only; a schedule and an agent's shell run
in the sandbox; Alpha Bridge pairs with the local Alpha and a lent file lands; Windows stops an idle
Linux within 150 s unless a hidden link holds it, which then kept it up. His own PC run was skipped
on his word: he tested the first setup file instead.

The build: the core knows a PC (`PcPlatform`, `ALPHA_ON_PC`) and starts Claude's sign-in there by
handing the window the page Claude would open, and taking back the code it shows; Alpha Bridge
takes plain http for this computer's own address only. Alpha's Linux is one image
(`release/windows/image.sh`) with the servers' own setup, made a PC's (its secrets' key handed in
from Windows, the service started by the app), smoke-tested, then exported. The Mac app's folder is
now `desktop/`, the Mac's and Windows' parts in their own files; the PC's (`desktop/src/pc/`) are
the engine's starter (`--engine`: the sealed key, the held-open link, the PC kept awake while
plugged in), the Install window (checks, WSL turned on with Windows' own prompt and a restart,
carrying on by itself after it, the image brought in, the start-at-sign-in entries), updates (a
newer setup carries the data over; Update from a file… takes Kenil's small signed release, made
by `pnpm server pc`), Make a report, notifications, uninstalling (the data saved in Documents),
and Alpha Bridge's part: its code run inside the app, paired with the PC's own Alpha by itself,
the PC's folders, browser and pause in the menu by the clock, and Set up Alpha's computer step
made the PC's own (This PC, Lend a folder, nothing installed).

On his PC: Smart App Control refused the unsigned setup outright, and he turned it off himself;
then the install worked. Claude's sign-in did nothing on Set up Alpha (fixed: the code pasted back),
and the step did not go on by itself after it (fixed, and sent as an update file). Signing the
setup is his to arrange.
