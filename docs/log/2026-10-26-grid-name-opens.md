# 26 October 2026: a row's name opens it

In the table grid, one click on the name in the first column opens the row, a quarter second later
so a double-click still changes it; a click elsewhere in that cell picks it, as in every other
cell. The small open icon that showed on hover is gone. Checked in Edge against the Circles table:
the name shows a pointer, a click opens the row panel, a click beside it opens the value's source,
a double-click edits.
