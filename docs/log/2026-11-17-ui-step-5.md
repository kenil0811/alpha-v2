# 17 Nov 2026: UI changes, step 5 (a map view)

Step 5, the last of the build order from the review of the 16 Nov UI change request: D27d, for
Waterways' car wash locations. Detail doc 2DLhZQnYs6xU5vuCh3Ejb7; Kenil took all four calls as
recommended ("ok for now" on leaving addresses for later).

- A table's places (`core/src/world/places.ts`, exported as `@alpha/core/places` for the window):
  a latitude and a longitude by name and range, or a column of points by its values. The core's
  view check lays a saved map on one, and the model may save a map.
- Map in the layout picker, greyed with its reason where a table has no place; its own picker
  when a table has several places, and Colour by a choice.
- MapLibre GL 6.16 (BSD), loaded only when a map opens, with its worker; OpenFreeMap's positron
  and dark styles follow the window's look. Points gather where they crowd; pointing names the
  row, a click opens it beside; the rows with no place are counted under the map.
- Addresses are not turned into points: that waits for Waterways' modules.
- Rules: T24 new; the design's window paragraph says which outside service the map reaches.
