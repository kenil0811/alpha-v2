# 26 October 2026: Files under a module

The sentence under Files becomes the section itself: a search box (Escape clears it), Upload on the
right, and the list of the module's files, each opening the file, with its row, size and date under
it. Upload hands the file to Alpha, which files it on the row it belongs to. The core has no list of
a module's files yet: the window asks `GET /api/modules/:id/files` and keeps the empty frame until
Kenil adds it. Checked in Edge at 1440×900 under Network.
