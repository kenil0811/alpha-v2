# 26 October 2026: the workspace menu

The rail's head was a link to Settings. It is now a menu: the workspace's tile and name ("On this
Mac"), Settings, Intelligence, Appearance (Match Mac, Light, Dark; kept in this browser and saved
through `/api/appearance`, as Settings › Appearance does), and Switch workspace, disabled with its
reason (one workspace per Mac). The folded rail's tile opens the same menu. Escape closes it and
leaves the assistant as it was. Window only; stacked on the menu PRs (#30) since it uses their menu.
