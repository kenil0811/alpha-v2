# 25 October 2026: approved rules typed in Governance

Vikas wants rules he types himself to count as approved. Governance is now two columns, Allowed n
and Denied n (stacked when narrow), each with + Add: an inline line, "Alpha may …" or "Alpha must
never …", saved with Save as a rule. The core keeps no rules of its own yet, so a typed rule is kept
as the person's own decision, Kept, in Alpha's Decisions ("In Network, Alpha must never …"), and
the module's Governance lists those that name it, with the day approved. Binding the model to them
is the core's part (proposals/2026-10-25-rules-marks-revert.md, items 1 to 3).
