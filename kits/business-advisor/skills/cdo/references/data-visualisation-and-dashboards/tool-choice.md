# Choosing the analytics tool

Depth for `cdo/references/data-visualisation-and-dashboards.md`.

## The tools and what each is for

| Tool | Strengths | Limits | Pick it when |
|---|---|---|---|
| **Tableau Desktop** | Fast drag-and-drop exploration; very wide range of custom charts; parameters, actions, stories; spatial functions; joins, unions, blends, pivots at connect time | Licence cost; custom charts need table-calculation skill | Visual exploration and polished interactive dashboards are the main need |
| **Tableau Prep Builder** | Visual, repeatable cleaning flows (union, join, clean, aggregate, pivot) with a profile of every field; outputs to extract, CSV or a published source; append or replace on each run | Separate tool; not for charts | Data from several messy files must be combined the same way every month |
| **Power BI Desktop / Service** | Free desktop; Excel-like interface; Power Query for shaping; a data model with relationships (star schema), calculated columns and measures; strong Microsoft and cloud connectors; natural-language questions; embedding and real-time streaming; Desktop builds, Service shares | Fewer custom chart types without add-ins | The business runs on Microsoft 365 or Azure, or needs a governed shared model cheaply |
| **Excel** (pivot tables, Power Query, Power Pivot, 3D Maps) | Everyone has it; Power Query is the same engine as Power BI's; 3D Maps makes animated geographic tours exported as video | Hard to share interactively; large data is slow | Small data, one-off analysis, or a geographic tour for a presentation |
| **Google Sheets** | Shared, live, functions that pull web data (stock prices with GOOGLEFINANCE); simple charts and scorecards | Limited chart control | A small team needs a shared live sheet and a simple dashboard |
| **Python, R** | Any statistic or model; reproducible charts as code (matplotlib, seaborn, plotly; ggplot2) | Needs coding; not self-service for managers | The method is beyond the BI tool, or the chart must be generated by a pipeline |
| **Tableau with R or Python** | Call R (through Rserve) or Python (through TabPy) from a calculated field with script functions (real, integer, string, boolean results) | Must run a server; slower; table-calculation semantics | Managers need a model output (correlation, regression, clustering) inside the dashboard |

Power BI and Tableau compared, in short: Power BI leans to an organisation-wide overview, an Excel-like interface and stronger infrastructure support; Tableau leans to data discovery for any user and easy embedding. Both connect to many sources and detect relationships.

## Decision rules

1. Who maintains it? A business user with no code: Tableau, Power BI or Excel. An analyst team with code: add Python or R.
2. Where does the data live? Microsoft stack favours Power BI; mixed sources favour either; a shared live sheet favours Google Sheets.
3. How often is it refreshed? Monthly and repeatable: build the preparation once as a flow (Tableau Prep, Power Query), not by hand.
4. Who views it and on what? Many viewers and phones: a server or cloud service with device layouts.
5. Cost: start with the free option that meets the need (Power BI Desktop, Tableau Public for non-confidential data, Google Sheets) (standard practice).

## Calling Python or R from Tableau (outline)

1. Install R with the Rserve package, or Python with TabPy, and start the server.
2. In Tableau, set up the analytics extension connection (host and port) and test it.
3. Write a calculated field with a script function; pass aggregated fields as arguments (for example the sum of sales and the sum of profit to get their correlation from numpy).
4. Use the field in a view; remember it is computed like a table calculation over the marks in the view.

## Using an AI model alongside the tool

- Ask it to write a Python chart for the same data; compare it with the BI version on clarity and accuracy.
- Ask it to critique and improve its own chart (self-critique), then check the improvement.
- Ask it to draft a calculated field; test it in the tool before trusting it.
- Always verify its stated numbers and takeaways against the tool's figures.
