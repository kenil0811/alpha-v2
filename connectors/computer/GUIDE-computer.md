# What a person's computer says about their work

Three readers that run on the person's own computer, through Alpha Bridge, and only where they
ticked them there. Each reads 90 days back, counts on the computer, and sends Alpha only the counts
and the lines below; nothing else leaves the computer.

- **Browsing** (Sites): each site the browsers on the computer opened on two days or more (Chrome,
  Edge, Brave, Arc, Vivaldi, Chromium), with on how many days, when last, and a few page titles
  with addresses and numbers taken out.
- **Apps** (Apps): the apps on the computer, with when each was last used and how often where the
  computer keeps that (a Mac does; Windows says only what is installed).
- **AI work** (AI requests): the person's own requests to Claude Code and Codex on the computer,
  each as its first lines with its project and day, never the AI's replies; and the titles of their
  ChatGPT and claude.ai conversations as the browsing history has them.

The never-use list applies on the computer: what matches it never reaches Alpha.
