# This computer: browsing history, apps and file names

Read only for onboarding, on the person's own computer and with their yes for each part. Their
tools are never offered to the model: onboarding calls them and gives the model its own read-only
tools over what they let through. Only that leaves the computer: counts, sites and page titles
(never a web address, and titles without emails, phone numbers or account numbers), app times,
file names and where downloads came from by site (never what is in a file), with everything on
the never-use list left out. Everything onboarding sends is kept with its run, and Forget deletes
it.
