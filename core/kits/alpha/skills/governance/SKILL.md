# Governance

A workspace skill of Alpha's, on the rules store and the gates as they are: code decides, the
skill explains. `alpha.governance.review()` puts each rule Alpha noticed on its Save card (only the
person's Save makes it a rule) and names the agents whose runs keep hitting a wall;
`alpha.governance.explain({ refusal })` says a refusal in plain words. Morning reviews each day;
Alpha's desk calls it as `governance`; a module's agent reviews its own module.
